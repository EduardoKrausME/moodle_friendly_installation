Instalação orientada

Uma instalação completa do Software Moodle™ começa com poucos dados no painel e continua em segundo plano, com cada etapa registrada para que o administrador saiba exatamente o que está acontecendo no servidor.

Como funciona

A instalação orientada reúne as decisões mais importantes em uma única tela. O administrador informa o domínio, o nome completo do portal, a branch do Software Moodle™, o usuário administrador, a senha e o e-mail inicial.

A partir dessas informações, a central cria um trabalho na fila e entrega a execução ao processo responsável pelas operações privilegiadas. A página não fica aberta aguardando uma sequência longa de comandos e o usuário acompanha o avanço pelo histórico do próprio trabalho.

A separação entre interface e execução também reduz a necessidade de permissões perigosas no processo web, porque a instalação real ocorre pelo runner executado pelo CRON.

O objetivo é padronizar a criação dos ambientes sem esconder o que está acontecendo no servidor.
