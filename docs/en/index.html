Installation orientada

Create a new environment
without building everything by hand.

Enter the domain, portal name, Moodle™ software version, administrator and initial data. The control center validates the request, creates a job and hands processing over to the server.

The browser does not need to stay blocked waiting for a long command sequence, and every step can be followed in the installation history.

Heavy work outside the browser

The panel organizes.
The server executes.

The interface validates the request and creates a job. The CRON runner, executed with the required server permissions, performs the processing in the background.

This avoids turning a web request into a privileged terminal while keeping operation progress recorded for review.

Tested configurations
