Maintenance controls

Debug, maintenance, cron, email delivery, caches and performance information can be controlled per domain, with the current state visible and a clear explanation of what each option does.

How it works

The control center treats these behaviors as flags tied to the domain. Each control shows its state, explains what will be changed and identifies the file used under /home/[domain].

The config.php generated by the panel reads these flags and applies the corresponding constants. This lets the administrator see directly on screen why an environment is showing debug messages, not sending emails or no longer running scheduled tasks.

Changes that depend on the server follow the same validation and queue flow used throughout the rest of the panel.

Maintenance becomes explicit per environment, avoiding forgotten settings and changes without context.
