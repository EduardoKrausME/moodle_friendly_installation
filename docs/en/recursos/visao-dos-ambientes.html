Overview of all environments

A central screen brings together server status, the number of installations, usage data and activity signals so the administrator does not need to open every portal just to understand the overall state of operations.

How it works

The overview was designed to be the first operational screen. It presents the main server resources while summarizing the managed installations.

The goal is not to display decorative numbers, but to provide a quick reading that helps decide which environment should be opened, which resource deserves investigation and whether observed activity matches what is happening across the portals.

Each domain remains independent, while the control center avoids the repetitive work of opening several installations just to discover where the problem is.

The control center organizes independent installations; it does not turn multiple portals into a single database.
