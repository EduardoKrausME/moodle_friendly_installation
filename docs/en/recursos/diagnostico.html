Diagnostics sem adivinhação

The control center brings together DNS, certificate, web server configuration, Moodle™ software data, resource usage and domain logs so investigation starts with evidence rather than random attempts.

How it works

The details page organizes diagnostics around the selected domain. Instead of presenting generic data for the entire server, it brings together information belonging to that installation and keeps shortcuts, resource usage, control flags, infrastructure checks and recent logs close at hand.

This domain-based scope reduces the classic risk of investigating one installation and changing another. DNS, SSL, configuration files, disk usage and logs appear in the same context.

When a validation depends on privileged access, the interface submits the job to the queue and receives the result later, keeping the browser out of root operations.

Diagnostics bom reduz tentativa e erro e deixa mais claro o que mudou antes e depois de uma intervenção.
