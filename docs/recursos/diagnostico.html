Recurso

Diagnóstico sem adivinhação

A central reúne DNS, certificado, configuração do servidor web, dados do Software Moodle™, consumo de recursos e logs do domínio para que a investigação comece pelas evidências e não por tentativas aleatórias.

Como funciona

A página de detalhes organiza o diagnóstico a partir do domínio selecionado. Em vez de apresentar dados genéricos do servidor inteiro, ela reúne as informações que pertencem àquela instalação e mantém próximos os atalhos, os recursos consumidos, as flags de controle, as verificações de infraestrutura e os registros recentes.

Esse recorte por domínio diminui o risco clássico de investigar uma instalação e alterar outra. DNS, SSL, arquivos de configuração, uso de disco e logs aparecem no mesmo contexto.

Quando alguma validação depende de acesso privilegiado, a interface solicita o trabalho para a fila e recebe o resultado depois, mantendo o navegador fora das operações de root.
