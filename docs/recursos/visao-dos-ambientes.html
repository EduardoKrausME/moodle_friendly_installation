Visão de todos os ambientes

Uma tela central reúne a situação do servidor, a quantidade de instalações, os dados de utilização e os sinais de atividade para que o administrador não precise abrir cada portal apenas para entender o estado geral da operação.

Como funciona

A visão geral foi criada para ser a primeira tela da operação. Ela apresenta os recursos principais do servidor e, ao mesmo tempo, resume o conjunto de instalações administradas.

O objetivo não é exibir números decorativos, mas oferecer uma leitura rápida que ajude a decidir qual ambiente precisa ser aberto, qual recurso merece investigação e se a atividade observada corresponde ao momento vivido pelos portais.

Cada domínio permanece independente, mas a central evita o trabalho repetitivo de abrir várias instalações apenas para descobrir onde está o problema.

A central organiza instalações independentes; ela não transforma vários portais em uma única base.
